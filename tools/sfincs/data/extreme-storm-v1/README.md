# Extreme what-if storm on the original 29,685-cell model

Deliberately far beyond anything on record, to see where bridges and homes go under. Not a
forecast or an observed event. Same as `stress-storm-v1` except:

- Rain Nov 2 00Z-06Z: NOAA Atlas 14 1000-year 6-hour storm at 32.40N 111.15W (4.00 in; peak
  hour 3.04 in), the same on every cell, no areal reduction.
- Santa Cruz inflow (source 1, reach 15902351): twice the stress hydrograph, peak 3,681 m3/s
  (2 x the Oct 2 1983 record at Cortaro, USGS 09486500) at Nov 2 05Z.

Run with case_archive `tools/sfincs/data/extreme-storm-v1/case.tar.gz`, cap 1200.
