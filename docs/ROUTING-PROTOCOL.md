# First routing benchmark: frozen protocol

Declared before calculating model scores against Trico September 2014.

- Predict **Santa Cruz discharge at USGS 09486520** from observed upstream **Cortaro 09486500** discharge. This is a retrospective routing hindcast, not a radar-runoff prediction, bridge-depth estimate or structural-failure prediction. The exact bridge in the owner's recollection remains unconfirmed.
- Primary calibration: July 28–August 4, 2006 flood, selected because its upstream flow scale brackets the 2014 event. The downstream peak includes an estimated flag; approved-but-qualified downstream samples are excluded from fitting. Upstream estimated samples remain labeled in the saved source and are used as uncertain boundary input. Channel changes between 2006 and 2014 limit transferability.
- Secondary, independently fitted diagnostic: July 19–23, 2013 flood (smaller storm, major extrapolation to 2014). Show both regardless of outcome. Do not choose the better one after seeing 2014 scores.
- One pure lag followed by one linear reservoir, fixed unit transmission and no tributary/lateral input. Lag and storage coefficient each range 0–720 minutes in 15-minute increments. Select minimum discharge RMSE against exact matched, approved unqualified target samples after a fixed first-day warm-up. Ties resolve in ascending lag/K order.
- Freeze selected parameters and SHA-256 hashes of the calibration input files before the scoring script reads the September 2014 target. The model starts with upstream initial flow; no downstream target value is used for initialization. Upstream is held piecewise constant between actual timestamps; gaps >30 min cause explicit failure. Before target scoring, inspection identified one 30-minute upstream gap on August 3, 2006 (well after the flood peak); its preceding value is held for that interval and the uncertainty remains documented. No missing value is replaced with zero. Output is on the UTC quarter-hour grid, never matched by row number.
- Score September 7–11, 2014, excluding the first 24h warm-up for **every** candidate and baseline. Report sample counts and exclusions, RMSE, NSE, bias, peak magnitude and timing errors, all available curves, and input source/quality information. No parameter adjustment after scoring.
- Baseline: upstream flow passed straight through at matching UTC times (zero lag, zero attenuation). This tests whether routing improves on doing nothing, not whether it beats an operational forecast model.
- The target's published peak and timing were already seen during research. Thus this is **not a blinded experiment**. A frozen separate-event fit prevents direct fitting to the 2014 target but does not erase that knowledge. Further independent events are required.

Established concept: the linear-reservoir limit of hydrologic storage routing, `dS/dt = I - O`, `S = K O`; our code integrates its constant-input exponential solution and adds a pure lag. See the [USACE Muskingum method](https://www.hec.usace.army.mil/confluence/hmsdocs/hmstrm/channel-flow/muskingum-model) for the general storage-routing framework. This implementation is not HEC-HMS/HEC-RAS software, and does not borrow third-party solver code. The local 2015 University of Arizona study documents a 16.4-mile reach and a calibrated HEC-RAS analysis, which is a next-step source of surveyed geometry rather than a claimed model already reproduced here.
