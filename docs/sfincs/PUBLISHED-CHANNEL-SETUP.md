# Published channel setup, evaluated without target fitting

This case reuses the official HydroMT-SFINCS 1.2.2 `setup_subgrid(datasets_riv=...)` workflow. It supplies the existing NOAA connected river paths with published HydroGeom bankfull top-width and depth estimates, joined by NHDPlusV2 COMID. It does not run GEB, subtract depth from each terrain pixel, or combine two channel-burning workflows. HydroMT estimates banks outside the river mask and applies its rectangular-channel approximation.

Data attribution: Zarrabi, McDermott, Erfani and Cohen (2025), https://doi.org/10.1029/2024WR037997 . Published dataset https://doi.org/10.5281/zenodo.19208847 , CC-BY-4.0, served by https://github.com/Reizrb/HydroGeom . Original API response, request, timestamp and hash are in `tools/sfincs/data/prefab-channel`. These are ML estimates, not local survey observations. Top width is approximated as rectangular width; channel depth is not absolute bed elevation. Modern training data preclude claiming historical independence.

The archived global SFINCS study https://doi.org/10.5281/zenodo.16759100 was inspected to verify its established `datasets_riv` build sequence and compatibility. Its own width/depth estimates use different inputs and are NOT the source of our HydroGeom dimensions. No claim that the entire archived framework is turnkey is made.

Same geometry is locked for both complete events BEFORE scoring: July5–23 2013 with retained qualified antecedent rainfall, and September7–11 2014. Native changes are the prepared subgrid and the independently mapped source point (491030.431,3579398.680), approximately98m from the recorded gauge coordinate. Gauge coordinates remain in provenance. Rainfall, observed upstream discharge, roughness0.04, infiltration0, levee, outlets, numerical settings and original comparison sections remain unchanged. No downstream hydrograph is used in construction. The existing executable is reused; no compilation.

`build_prefab_channel.py REPOSITORY` records the official preparation. `stage_prefab_case.py SOURCE NEW_CASE` applies the saved native subgrid to preserved event inputs with hash checks. Both refuse to overwrite prior evidence. These are input adapters, not new hydrodynamic algorithms. Results must be reported for both events, including failures; this is a post-failure method evaluation, not blind validation.
